# しょーかんハッピーズ

Socket.IO を使った2人対戦対応のカードゲームです。

## ローカル起動

```bash
npm install
npm start
```

起動後、ブラウザで `http://localhost:3000` を開きます。

## iPhoneでホーム画面に追加する

このゲームはPWAとしてホーム画面に追加できます。完全なオフラインプレイには対応していないため、起動と対戦にはオンライン接続が必要です。

1. iPhoneのSafariで公開URLを開く。
2. 画面下の共有ボタンを押す。
3. 「ホーム画面に追加」を選ぶ。
4. 名前が「しょーかんハッピーズ」になっていることを確認して「追加」を押す。
5. ホーム画面に追加されたアイコンから起動する。

ホーム画面から起動すると、Safariのアドレスバーが出にくいアプリ風の表示になります。通信できない状態で開いた場合は「オンライン接続が必要です」と表示されます。

## オンライン対戦

1. タイトル画面で「マルチ対戦」を押す。
2. 「ランダム対戦」または「友達と対戦」を選ぶ。
3. 友達と対戦では、部屋を作った側が表示されたパスワードまたはURLを相手に共有する。
4. 2人そろうと自動で対戦が始まります。

ゲーム状態はサーバー側で管理します。手札、山札順、裏向きの持ち物などの非公開情報は相手に見えないように送信されます。

## Render

Render の Web Service として公開できます。

- Build Command: `npm install`
- Start Command: `npm start`
- Environment: Node
- Health Check Path: `/healthz`

`PORT` は Render から渡される値を `server.js` が自動で使用します。
